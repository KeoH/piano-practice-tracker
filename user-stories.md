User stories

- como usuario quiero tener una nueva seccion en la app que me rete a mejorar cada vez
- como usuario quiero una especie de modo de juego en el que compito con mi "yo" anterior
- como usuario quiero poder tocar una melodia dada, ajustando el tempo para hacerlo mas facil o mas dificil y que mida mi porcentaje de acierto de las notas
- como usuario quiero que quede registro de mi participacion en cada intento, puntuacion y errores cometidos
- como usuario quiero que en la pantalla de estadisticas se vea de alguna manera mi progreso en una determinada melodia con los intentos realizados
